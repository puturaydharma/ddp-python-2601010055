## Daftar latihan
1. `latihan1_biodata.py`: menampilkan biodata mahasiswa dengan f-string
2. `latihan2_persegi_panjang.py`: menghitung luas & keliling persegi panjang beserta trace table
3. `latihan3_konversi_suhu.py`: konversi suhu Celsius ke Fahrenheit & Kelvin dengan 2 angka desimal
4. `latihan4_total_belanja.py`: menghitung subtotal, PPN 11%, & total bayar belanjaan

## Cara Menjalankan Program
Pastikan Python sudah terinstal. Buka terminal di folder proyek ini, lalu jalankan:

### Windows (Command Prompt / PowerShell)
```bash
python latihan1_biodata.py
python latihan2_persegi_panjang.py
python latihan3_konversi_suhu.py
python latihan4_total_belanja.py
```

### macOS / Linux
```bash
python3 latihan1_biodata.py
python3 latihan2_persegi_panjang.py
python3 latihan3_konversi_suhu.py
python3 latihan4_total_belanja.py
```
